# Hook and CTA Library

Use these as starting patterns. Replace bracketed text with verified context and rewrite naturally.

## Hook patterns

### Curiosity
- "ഇത് ചെയ്യുമ്പോൾ പലരും ശ്രദ്ധിക്കാതെ പോകുന്ന ഒരു കാര്യമുണ്ട്…"
- "[വിഷയം] സംബന്ധിച്ച് ആദ്യം അറിയേണ്ടത് ഇതാണ്."
- "നിങ്ങൾ [task] ചെയ്യാറുണ്ടോ? ഈ ചെറിയ കാര്യം ശ്രദ്ധിക്കൂ."

### Problem-led
- "[പ്രശ്നം] നിങ്ങളെയും അലട്ടുന്നുണ്ടോ?"
- "[പ്രശ്നം] ഒഴിവാക്കാൻ ആദ്യം പരിശോധിക്കേണ്ടത് ഇതാണ്."
- "ഇത് വീണ്ടും വീണ്ടും സംഭവിക്കുന്നുണ്ടെങ്കിൽ, കാരണം ഇതായിരിക്കാം."

### Benefit-led
- "[ആവശ്യം] എളുപ്പമാക്കാൻ സഹായിക്കുന്ന ഒരു മാർഗം."
- "സമയം ലാഭിക്കാൻ സഹായിക്കുന്ന [number] പ്രായോഗിക നിർദ്ദേശങ്ങൾ."
- "[Audience] ഉപകാരപ്പെടുന്ന ഒരു ലളിതമായ tip."

### Story-led
- "ഒരു ചെറിയ അനുഭവത്തിൽ നിന്ന് പഠിച്ച കാര്യം…"
- "ആദ്യം ഞങ്ങൾ കരുതിയത് [assumption] ആയിരുന്നു. പക്ഷേ…"
- "ഈ യാത്രയിൽ മനസ്സിലാക്കിയ ഏറ്റവും പ്രധാനപ്പെട്ട പാഠം…"

Use only when the underlying story or experience is true and supplied.

### Product-led
- "[Use case] നോക്കുന്നവർക്ക് പരിചയപ്പെടാം: [product]."
- "[Product] തിരഞ്ഞെടുക്കുമ്പോൾ ശ്രദ്ധിക്കേണ്ട [feature]."
- "ദൈനംദിന [task]-നായി രൂപകൽപ്പന ചെയ്ത [product] — [verified detail]."

### Community-led
- "നിങ്ങളുടെ അനുഭവം എന്താണ്?"
- "ഇവയിൽ നിങ്ങൾ തിരഞ്ഞെടുക്കുന്നത് ഏതാണ്?"
- "[Topic] സംബന്ധിച്ച് നിങ്ങളുടെ അഭിപ്രായം അറിയിക്കാമോ?"

## CTA patterns

### Conversation
- "നിങ്ങളുടെ അഭിപ്രായം കമന്റിൽ പങ്കുവെക്കൂ."
- "നിങ്ങൾ ഇതിൽ ഏത് രീതിയാണ് പിന്തുടരുന്നത്?"
- "ഇതുമായി ബന്ധപ്പെട്ട നിങ്ങളുടെ സംശയം ചോദിക്കൂ."

### Enquiry
- "വിശദാംശങ്ങൾ അറിയാൻ ഞങ്ങൾക്ക് മെസേജ് അയക്കൂ."
- "ലഭ്യതയും മറ്റ് വിവരങ്ങളും അറിയാൻ ബന്ധപ്പെടൂ."
- "നിങ്ങളുടെ ആവശ്യത്തിന് അനുയോജ്യമാണോ എന്ന് ചോദിച്ചറിയൂ."

### Traffic
- "കൂടുതൽ വിവരങ്ങൾക്കായി [confirmed link] സന്ദർശിക്കൂ."
- "പൂർണ്ണ വിശദാംശങ്ങൾ ഇവിടെ വായിക്കാം: [confirmed link]."

### Booking / visit
- "ബുക്കിംഗിനായി [confirmed contact] വഴി ബന്ധപ്പെടൂ."
- "സന്ദർശിക്കുന്നതിന് മുമ്പ് സമയം ഉറപ്പാക്കൂ: [confirmed contact]."

### Purchase
- "ഓർഡർ ചെയ്യാൻ [confirmed method] ഉപയോഗിക്കൂ."
- "വിലയും ലഭ്യതയും സ്ഥിരീകരിക്കാൻ മെസേജ് അയക്കൂ."

## CTA rules
- One post, one primary CTA.
- Match CTA to the post objective.
- Do not ask for a message, call, click, comment, and share all at once.
- Never create fake scarcity, false deadlines, or pressure.
- Include contact details only when supplied.
