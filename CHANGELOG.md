# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-17

### Added
- Standalone Malayalam-first Facebook content-generation Skill.
- Facebook post formats, hook and CTA library, brand-voice guidance, and quality/safety checks.
- Sample output and quick-start prompts.
- Installation guidance for Claude and Manus Cue-compatible Skill managers.

### Scope
- Content drafting and planning only.
- No automatic Facebook publishing, scheduling, moderation, or analytics without separate integrations.
